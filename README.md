# CCTV Scanner OTA

Repositorio de distribución de firmware OTA para CCTV Scanner ESP32.

- **Manifiesto estable:** https://raw.githubusercontent.com/resKte/cctv-scanner-ota/main/ota/stable.json
- **Firmware:** cada versión se publica como `firmware.bin` en sus Releases.

El dispositivo consulta el manifiesto y solicita confirmación antes de instalar una actualización. La OTA de extremo a extremo aún debe probarse en el equipo.
